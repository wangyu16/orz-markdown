The {{ }} plugins

One uniform syntax for rich embeds: {{name args}} inline, or {{name⏎…⏎}} across lines. No HTML required.

Common mistake: a fenced code block named after a plugin renders as plain code, with no warning. Write {{mermaid … }}, not ```mermaid … ``` — and the same for {{chart …}}, {{smiles …}} and {{qr …}}. There is no closing tag: every directive ends with }}.

The ::: containers

Semantic callouts and real layout, from fenced blocks. Nest by adding colons to the outer block.

Markdown
Renders to
All container types

Callouts: info, success, warning, danger. Layout: left / right / center, cols, tabs, spoil (spoiler). Any other ::: ClassName becomes a <div class="ClassName">, so you can style your own. Printed, every tab shows under its label.

Nesting: every level that holds another container needs more colons than what it holds — a callout inside a column is ::::: cols › :::: col › ::: info.

::: info        ::::  cols 1 2        :::: tabs
…content…       ::: col              ::: tab One
:::             …                    …
                :::                  :::
                ::::                 ::::

Math with KaTeX

Inline $…$ and display $$…$$, rendered at parse time. mhchem is bundled for chemistry. Macro definitions (\def, \newcommand) are not supported and show as source — write the expanded TeX; a formula over 10,000 characters also shows as source.

Diagrams & charts

Flowcharts, data charts, and chemistry, all from plain text, drawn in the theme's colours. (These libraries load on demand, and draw only once their part of the page is visible.) Theme colours for charts and diagrams are new in orz-markdown 2.4: they apply to pages rendered with orz-markdown 2.4 and to orz-slides 1.0 decks, and reach .md.html and .paged.html files when orz-mdhtml and orz-paged move to kit 2.4 (their 1.0 releases embed 2.3 and draw charts in Chart.js's default colours).

Twelve built-in themes

Light and dark, academic to playful. A theme styles the full rendered output, including containers, math, diagrams, and print. Switch instantly in the editor.

Neat

Clean and modern; three variants (sans or Literata serif text), including Orchard.

Academic & Beige

Serif, paper-like, for reports; four themes.

Dark Elegant

Three refined dark themes, including Nocturne.

Playful

Hand-drawn: a ruled notebook and a sketchbook.

The twelve, by name and id (the id is what a header's theme: takes): Orchard light-neat-3 (the default for documents), Neat light-neat-1, Neat 2 light-neat-2, Academic light-academic-1, Academic 2 light-academic-2, Beige beige-decent-1, Beige 2 beige-decent-2, Playful light-playful-1 (a ruled notebook), Playful 2 light-playful-2 (a sketchbook), Dark Elegant dark-elegant-1, Dark Elegant 2 dark-elegant-2, Nocturne dark-elegant-3.

Line length is the reader's choice: every theme reads at about 70 characters a line; measure-wide gives about 90 (tables, code, dense notes) and measure-full the whole width — in an .md.html, the header's measure: wide or full.

Chinese and English, side by side

Emphasis works next to CJK punctuation (**注意：**请先阅读), a line wrap between Chinese characters adds no space, and a bare URL next to Chinese links only the URL (访问https://orz.how获取). Chinese written onto a URL path stays in the link, so put a space or punctuation after a URL that prose follows.

Copy as Markdown

With the browser runtime loaded, selecting rendered content and copying puts Markdown source on your clipboard, not HTML.

It round-trips

Tables, lists, math, code, and even generated constructs survive the trip. Copy a rendered QR and you get {{qr …}} back; copy a diagram and you get its {{mermaid …}} source.

Why it matters

Your rendered document stays the source of truth. Paste into any editor, chat, or issue and it is clean, portable Markdown again, ready to re-render anywhere.
