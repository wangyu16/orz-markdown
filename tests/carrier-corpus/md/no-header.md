# Reading a Burette

A plain Markdown file with no document header. Every existing `.md` file is a
valid `md` document, so this one must open, render and round-trip unchanged.

1. Fill the burette above the zero mark and drain to just below it.
2. Read the bottom of the meniscus at eye level.
3. Record the reading to the nearest 0.01 mL.

| Reading | Volume (mL) |
|---|---|
| Initial | 0.35 |
| Final | 24.80 |
| Delivered | 24.45 |

The title of this document comes from the first level-1 heading above.
